Политика конфиденциальности

Последнее обновление: 25 августа 2026 г.

Общие положения

LT Learn — приложение для изучения литовского языка. Эта политика описывает, какие данные обрабатывает приложение, для каких целей и как с нами связаться по вопросам конфиденциальности.

Данные, которые обрабатывает приложение

Приложение не собирает имя, адрес электронной почты, номер телефона, содержимое добавленных пользователем наборов слов или ответы в упражнениях.

Прогресс обучения, выбранные настройки и добавленные пользователем наборы слов сохраняются локально на устройстве пользователя. Эти данные не отправляются разработчику или третьим лицам.

Приложение использует Firebase Analytics и Firebase Crashlytics от Google LLC. Эти сервисы автоматически обрабатывают следующие данные:

  • сведения о взаимодействии с приложением, включая запуск и завершение тренировки, тип тренировки, количество слов и этапов, идентификаторы встроенных наборов, факт использования пользовательского набора и нажатие кнопки «Поделиться»;
  • приблизительное местоположение, определённое из маскированного IP-адреса;
  • идентификаторы установки и устройства, включая Firebase Installation ID, Firebase App Instance ID и Advertising ID;
  • технические сведения об устройстве и приложении, а также журналы сбоев и стек вызовов при сбое приложения.

Содержимое и названия пользовательских наборов слов, а также ответы в упражнениях в Firebase не передаются.

Цели обработки

Анонимизированные данные используются для анализа использования приложения, улучшения его стабильности и устранения ошибок. Приложение не показывает рекламу, не продаёт пользовательские данные и не использует данные для маркетингового профилирования.

Передача и защита данных

Данные аналитики и отчёты о сбоях передаются в Firebase, сервис Google LLC, по защищённому соединению TLS. Firebase обрабатывает эти данные от имени разработчика для предоставления сервисов аналитики и отчётов о сбоях.

Если пользователь сам воспользуется функцией «Поделиться», выбранный им материал будет передан только приложению, которое пользователь выберет в системном меню Android.

Хранение и удаление данных

Локальные данные можно удалить, очистив данные приложения или удалив приложение в настройках Android.

Firebase хранит данные в соответствии со своими сроками хранения и настройками проекта Firebase. При необходимости удалить данные, связанные с использованием приложения, пользователь может обратиться к разработчику по адресу, указанному ниже.
